# Lang Switcher

Утилита для Windows, которая живёт в трее и исправляет текст, набранный не в той
раскладке. Напечатали `руддщ` вместо `hello` — нажмите **Break**, и слово станет
`hello`, а раскладка переключится на английскую. Нажмите **Break** ещё раз —
вернётся то, что было набрано изначально.

Программа ничего не угадывает и не правит текст сама: всё происходит только по
вашему нажатию, поэтому правильно набранное слово она не тронет.

---

## Быстрый старт

1. Распакуйте архив в любую папку.
2. Запустите `LangSwitcher.exe` — в области уведомлений появится значок.
3. Наберите слово не в той раскладке и нажмите **Break**.

При первом запуске рядом с EXE создастся `config.ini`. Программа портативная:
в профиль пользователя и системные папки она ничего не пишет.

---

## Клавиша Break

Действие зависит от ситуации:

- **Вы только что набрали слово.** Оно стирается и печатается заново в соседней
  раскладке. Повторное нажатие возвращает исходный вариант.
- **Вы выделили текст.** Выделенный фрагмент конвертируется в другую раскладку,
  буфер обмена при этом сохраняется.
- **Ничего не набрано и не выделено.** Break просто переключает раскладку на
  следующую по списку.
- **Поле ввода пароля.** Нажатия не запоминаются, Break лишь переключает раскладку.

Клавишу можно поменять в настройках: другая клавиша, комбинация с `Ctrl` / `Alt` /
`Shift` (например `Ctrl+F12`) или **двойное нажатие `Shift`**.

## Значок в трее

Значок показывает язык текущей раскладки активного окна. Иконки лежат в папке
`icons` рядом с EXE и называются по коду языка (LCID):

```
LangSwitcher.exe
config.ini
icons\
  1033.ico   ← английская раскладка
  1049.ico   ← русская раскладка
  ...        ← любой другой язык
```

Иконки меняются автоматически при смене раскладки или активного окна. Если файла
для языка нет, показывается встроенный нейтральный значок, а в режиме
«приостановлено» — встроенный серый.

Меню по правому клику на значке:

| Пункт | Действие |
|---|---|
| Приостановить | программа временно пропускает клавиши мимо себя (значок сереет) |
| Настройки… | окно настроек |
| Запускать вместе с Windows | включает автозапуск |
| О программе… | версия и краткая справка |
| Выход | завершить работу |

Двойной клик по значку открывает настройки.

## Настройки

Окно настроек состоит из трёх вкладок — «Основные», «Клавиша» и «Раскладки».
Изменения сохраняются сразу и действуют немедленно.

То же самое хранится в `config.ini` рядом с EXE:

```ini
[general]
autostart=0        ; 1 — запуск вместе с Windows
start_paused=0     ; 1 — запускаться в режиме «приостановлено»
debug_log=0        ; 1 — писать debug.log рядом с EXE (для диагностики)

[hotkey]
vk=19              ; код клавиши (19 = Break, 123 = F12, 20 = CapsLock)
mods=0             ; модификаторы: 1=Alt, 2=Ctrl, 4=Shift (сумма; 0 — без модификаторов)
double_tap=0       ; 1 — двойное нажатие Shift вместо одиночной клавиши

[layouts]
cycle=00000409,00000419   ; порядок переключения, коды KLID через запятую
                          ; пусто — все раскладки системы
```
