# Lang Switcher

Небольшая утилита для Windows, которая живёт в трее и исправляет текст, набранный
не в той раскладке. Напечатали `руддщ` вместо `hello` — нажмите **Break**, и слово
тут же станет `hello`, а раскладка переключится на английскую. Нажмите **Break**
ещё раз — и вернётся ровно то, что было набрано изначально.

Программа ничего не угадывает и не правит текст сама: конвертация происходит
только по вашему нажатию, поэтому правильно набранное слово она никогда не тронет.

Написана на чистом C++/Win32, собирается в один 32-битный EXE примерно 380 КБ,
не требует установки и работает начиная с Windows XP (как 32-, так и 64-битной).

---

## Быстрый старт

1. Положите `LangSwitcher.exe` в любую папку.
2. Запустите — в области уведомлений появится значок.
3. Наберите слово не в той раскладке и нажмите **Break**.

При первом запуске рядом с EXE создастся `config.ini`. Программа полностью
портативная: в профиль пользователя и в системные папки она ничего не пишет
(единственное исключение — необязательный автозапуск, который вы включаете сами).

---

## Клавиша Break и что она делает

Действие зависит от контекста:

- **Вы только что набрали слово.** Оно стирается и печатается заново в соседней
  раскладке. Повторное нажатие возвращает исходный вариант — и так можно
  переключаться туда-обратно сколько угодно раз.
- **Вы выделили текст.** Выделенный фрагмент конвертируется в другую раскладку.
  Буфер обмена при этом полностью сохраняется и возвращается обратно.
- **Ничего не набрано и не выделено.** Break просто переключает раскладку на
  следующую по списку.
- **Поле ввода пароля.** Здесь программа не запоминает нажатия вообще, а Break
  лишь переключает раскладку.

Клавишу можно поменять в настройках: назначить другую клавишу, комбинацию с
`Ctrl` / `Alt` / `Shift` (например `Ctrl+F12`) или **двойное нажатие `Shift`**.

Границы слова определяются естественно: стрелки, `Esc`, `Enter`, `CapsLock`, клик
мышью и команды с `Ctrl`/`Alt` сбрасывают запомненные нажатия, поэтому под Break
попадает ровно то слово, которое вы набираете прямо сейчас.

## Значок в трее

Значок показывает язык текущей раскладки активного окна. Иконки берутся из папки
`icons` рядом с EXE и называются по коду языка (LCID):

```
LangSwitcher.exe
config.ini
icons\
  1033.ico   ← английская раскладка
  1049.ico   ← русская раскладка
  1058.ico   ← украинская
  ...        ← любой другой язык
```

Иконки подхватываются на лету и меняются автоматически при смене раскладки или
активного окна. Если файла для языка нет, показывается встроенный нейтральный
значок, а в режиме «приостановлено» — встроенный серый. Оптимальный размер —
16×16, но можно положить в `.ico` и несколько размеров.

Меню по правому клику на значке:

| Пункт | Действие |
|---|---|
| Приостановить | программа временно пропускает все клавиши мимо себя (значок сереет) |
| Настройки… | окно настроек |
| Запускать вместе с Windows | включает автозапуск |
| О программе… | версия и краткая справка |
| Выход | завершить работу |

Двойной клик по значку открывает настройки.

## Настройки

Окно настроек состоит из трёх вкладок — «Основные», «Клавиша» и «Раскладки».
Все изменения сохраняются сразу и вступают в силу немедленно.

То же самое хранится в `config.ini` рядом с EXE:

```ini
[general]
autostart=0        ; 1 — запуск вместе с Windows
start_paused=0     ; 1 — запускаться в режиме «приостановлено»
debug_log=0        ; 1 — писать debug.log рядом с EXE (для диагностики)

[hotkey]
vk=19              ; код клавиши (19 = Break, 123 = F12, 20 = CapsLock)
mods=0             ; модификаторы: 1=Alt, 2=Ctrl, 4=Shift (сумма; 0 — без модификаторов)
double_tap=0       ; 1 — двойное нажатие Shift вместо одиночной клавиши

[layouts]
cycle=00000409,00000419   ; порядок переключения, коды KLID через запятую
                          ; пусто — использовать все раскладки системы
```

## Как это устроено внутри

- **Слово.** Программа запоминает сами нажатия — скан-коды клавиш, а не готовый
  текст. По Break она стирает слово (Backspace по количеству введённых символов),
  просит окно переднего плана сменить раскладку (`WM_INPUTLANGCHANGEREQUEST`) и
  заново отправляет те же скан-коды через `SendInput` с флагом `KEYEVENTF_SCANCODE`.
  Новую раскладку интерпретирует уже сама Windows, поэтому корректно
  воспроизводятся `Shift`, `AltGr` и «мёртвые» клавиши.
- **Выделение.** Фрагмент копируется в буфер (пробный `Ctrl+C`, запасной `Ctrl+Ins`),
  конвертируется по таблицам соответствия раскладок (строятся через `ToUnicodeEx`),
  вставляется обратно, а буфер обмена восстанавливается во всех форматах.
- **Раскладки.** Переключение идёт по настраиваемому списку; программа работает
  с раскладками, установленными в системе.

## Сборка из исходников

### Windows (MSYS2)

> `pacman` — это пакетный менеджер **MSYS2** (Unix-подобной оболочки для Windows),
> а не утилита самой Windows: в обычных `cmd`/`PowerShell` его нет. Команды ниже
> выполняются в оболочке **MSYS2 MinGW 32-bit**, которую pacman и обслуживает.
> Без MSYS2 локальная сборка не нужна — готовый EXE собирает GitHub Actions.

```bash
pacman -S mingw-w64-i686-toolchain mingw-w64-i686-cmake mingw-w64-i686-ninja
cmake -G Ninja -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
# готовый файл: build\LangSwitcher.exe
```

Тот же результат даёт `build.bat`, если запустить его из оболочки
*MSYS2 MinGW 32-bit* (или из `cmd` с `C:\msys64\mingw32\bin` в `PATH`).

### Linux (кросс-сборка)

```bash
sudo apt install mingw-w64 cmake ninja-build
cmake -G Ninja -B build -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-mingw32.cmake
cmake --build build
```

### GitHub Actions

Файл `.github/workflows/build.yml` на каждый push собирает 32-битный EXE в
MSYS2/MINGW32, проверяет PE-заголовки (подсистема 5.01 = Windows XP) и список
импортов, а затем упаковывает портативный архив `LangSwitcher-win32.zip`:
EXE + короткий пользовательский README (из `packaging/`) + папку `icons/`,
если она есть в репозитории (сборка иконки не генерирует, только копирует
готовые). Пуш тега вида `v*` дополнительно создаёт релиз GitHub с этим архивом.

## Состав проекта

```
src/
  main.cpp      точка входа, скрытое окно, автозапуск, цикл сообщений
  hook.cpp      низкоуровневые хуки клавиатуры и мыши, запись нажатий, ловля Break
  action.cpp    конвертация: слово, возврат, выделение, простое переключение
  layouts.cpp   раскладки: перечисление, KLID↔HKL, порядок, смена раскладки окна
  convert.cpp   таблицы раскладок (ToUnicodeEx) и посимвольная конвертация
  settings.cpp  чтение/запись config.ini рядом с EXE
  tray.cpp      значок в трее, иконки языков, контекстное меню
  dialogs.cpp   окно настроек (вкладки «Основные», «Клавиша», «Раскладки»)
  log.cpp       необязательная диагностика (debug.log)
  compat.cpp    совместимость с Windows 2000/XP RTM
  ui.rc         диалоги, значки, версия, манифест
packaging/
  README.md     короткая пользовательская инструкция (кладётся в архив)
tools/
  make_icon.py  генерация встроенных иконок программы (нужен Pillow)
cmake/
  toolchain-mingw32.cmake   кросс-сборка под i686-w64-mingw32
icons/          ваши иконки раскладок: 1033.ico, 1049.ico…
```
